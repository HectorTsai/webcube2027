# auth-gateway 版本紀錄

> 版本紀錄已從規格書獨立出來。以里程碑計數：每個里程碑 `+0.1.0`，初始 `0.1.0`。

| 版本 | 日期 | 說明 |
|------|------|------|
| 0.25.0 | 2026-08-05 | **Seed 版本化同步**：seed 寫入改用 `@dui/framework` 的 `seed-sync`（`syncAllSeeds`），以內容 hash（SHA-256）比對版本（存於本機 `data/config.json` 的 `seed_hash_L1` / `seed_hash_L2`），版本不同時**依 collection:model 分組以批次 PUT（upsert）** 覆寫至 data-gateway L1/L2（data-gateway 批次 CRUD，同組記錄一次 HTTP request）。安裝時（`/api/setup`）首次寫入並記錄版本；每次啟動（`main.ts`，非阻斷）偵測 seed 檔案變更自動覆寫，**不需刪除資料庫重來**。刪除本端 `database/seed-loader.ts`（`writeSeeds` / `loadSeedsRecursive` 由 framework 取代）。 |
| 0.23.0 | 2026-08-05 | 消除 HTTP loopback：`verifyUser` 邏輯抽出為共用服務函式（`services/verify-user.ts`），`localProvider.login` 與 `/api/verify-user` 端點直接呼叫，不再向自身發 HTTP 請求。`getDataGatewayUrl()` 改回傳 `string | null`、所有 9 個呼叫端優雅降級（匿名 token 返回空權限、gwFetch 端點回傳 502）。`hexToBytes()` 加入 hex 格式與長度防禦性驗證。`@dui/framework` 補匯出 `PermissionMap` 與 `mergePermissions`。seed-loader 註解修正。 |
| 0.22.0 | 2026-08-04 | `/api/register` 重構為租戶公開註冊：一律寫入 L3（L3 不存在直接回 400）、不接受指定角色（第一位註冊→管理員、其後→會員）、tenant 依序從 body/cookie 訪客 JWT/Host 推斷。data-gateway 徹底移除 L3→L2 降級：db-manager 新增 `ensureL3`（租戶無 L3 連線時拋錯），`list/getById/create/update/patch/deleteRecord` 與 crud `handleCollection` 不再靜默降級。site-gateway `/api/site/apply` 呼叫 register 補傳 tenant。 |
| 0.19.0 | 2026-08-03 | `/api/me` 改用 `id`（`payload.sub`）取代 `帳號` 作為使用者識別碼，新增 `名稱` 欄位（MultilingualString）；`AuthPayload` 新增 `名稱?` 欄位。navbar 顯示名稱優先取 MultilingualString 本地語言。doc.md 同步更新。 |
| 0.21.0 | 2026-08-04 | 新增 `/api/user/all`、`/api/role/all` 跨層查詢 API，平行查詢 data-gateway L1/L2/L3 三層並以「來源」欄位標示資料所屬層級。名稱欄位全系列 API（含 `/api/user`、`/api/user/:id`、`/api/role`、`/api/role/:id`）加入 `toTitleCase` 美化英文顯示。角色查詢路徑修正為 `/使用者/角色`（composite ID 的 collection/model 拆分）。data-gateway L3 移除無租戶降級 L2 的行為。@dui/framework 0.5.1 修復 `del.ts` 未對應 `DELETE` 路由的 bug。`/api/register` 預設角色由超級管理員改為會員（安全修正）。`/api/user`、`/api/role` 系列補上角色權限檢查（`utils/require-auth.ts`：JWT 驗證 + `checkAccess`「使用者」collection 讀權限；管理員 seed 增加 `"使用者": { "讀": true, "寫": false }`）。 |
| 0.20.0 | 2026-08-04 | 新增 `/api/user`、`/api/user/:id`、`/api/role`、`/api/role/:id` 查詢 API。啟用 Deno tsgo（Go 原生 TypeScript 檢查器）。 |
| 0.18.2 | 2026-08-03 | 登入的 tenant 改為可選：L2 使用者（超級管理員）屬系統層、不隸屬租戶，登入不需 tenant。移除 `POST /api/login` 與 `localProvider` 的強制 tenant 401 檢查；已認證 JWT payload 僅在 L3 登入時寫入 tenant。 |
| 0.18.1 | 2026-08-03 | 修正登入時無法識別租戶：`POST /api/login` 的 tenant 取得順序新增 Host header 推斷 fallback（不含埠號）；登入頁 GET 在無 `?tenant=` 時改從 Host header 推斷並自動簽發訪客 JWT cookie。適用於直接訪問 auth-gateway 登入頁（如 navbar 登入按鈕）的系統管理介面場景。 |
| 0.18.0 | 2026-08-03 | navbar 加入登入/登出按鈕：`_layout.tsx` 以客戶端 JS 呼叫公開 `/api/me` 判斷登入狀態——未登入顯示「登入」（導向 `/:lang/login`），已登入顯示登入者帳號與「登出」（導向 `/api/logout?redirect=...` 回原頁）。所有頁面（含 .md doc）共用。 |
| 0.17.0 | 2026-08-03 | 公開 API 架構化：移除根 middleware 的 PUBLIC_API_PATHS 硬編碼清單，改為 `/api/*` 一律預設公開（根 `_middleware.ts` 僅注入 `已安裝` context）。依賴 data-gateway 的 API 改在自身目錄放 `_middleware.ts` 限制（login、verify-user 需已安裝，未安裝回 403）。`/health` 列入公開路徑前綴（自行處理 data-gateway 未就緒的 degraded 狀態）。規格書同步更新。 |
| 0.16.0 | 2026-08-03 | 超管理者帳號移入 setup：`/api/setup` 新增必填 `帳號`／`密碼`，在寫入 L1/L2 seed 後以 bcryptjs 雜湊密碼並透過 L2 CRUD（`POST /api/l2/使用者/使用者`，角色 `使用者:角色:超級管理員`）建立初始超管理者帳號（已存在則跳過）；安裝頁面新增超管理者帳號／密碼欄位。data-gateway setup 不再建立任何帳號（只專注 L2 資料庫與 Master Key）。規格書同步更新。 |
| 0.15.0 | 2026-08-03 | 權限工具統一至 `@dui/framework`：`mergePermissions()` 與 `PermissionMap` 等型別改由 `@dui/framework` 的 permission 模組匯入（`/api/verify-user` 更新 import），刪除本端 `utils/permission.ts` 複本（原為 data-gateway 搬入的副本）。data-gateway 同步移除殘留的角色權限檢查，成為純資料層。 |
| 0.14.0 | 2026-08-03 | setup 寫入 L1/L2 seed：安裝流程在向 data-gateway 註冊取得 API Key 後，呼叫 `writeSeeds(baseUrl, apiKey, 'L1')` 與 `writeSeeds(baseUrl, apiKey, 'L2')`，將 `database/seeds/`（L1、L2 兩層）下的 JSON 種子逐筆透過 CRUD API 寫入（L1 → `POST /api/l1/:collection/:model`、L2 → `POST /api/l2/:collection/:model`，攜帶 `X-API-Key` header），已存在（409）跳過（冪等）。L1 seed：訪客角色＋訪客使用者；L2 seed：訪客/超級管理員/管理員/會員/貴賓/黑名單 角色＋訪客使用者（site/apply 依賴的預設角色由此提供）。seed-loader 的 `loadSeeds` 不再被其他流程呼叫（僅供 setup 的 `writeSeeds` 內部使用）。 |
| 0.13.0 | 2026-08-03 | create-admin 遷移至 `/api/register`：新增 `POST /api/register` 端點，在本端以 bcryptjs 雜湊密碼後透過 L2 CRUD（`POST /api/l2/使用者/使用者`）建立使用者紀錄，預設角色為 `使用者:角色:超級管理員`。加入 PUBLIC_API_PATHS。site-gateway 的 `/api/site/apply` 已改為呼叫此端點。data-gateway 的 `/api/l2/create-admin` 端點已移除。 |
