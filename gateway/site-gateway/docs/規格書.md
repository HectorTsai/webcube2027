# site-gateway 規格書

> 最後更新：2026-08-03

---

## 1. 概述

site-gateway 是 WebCube2027 的**網站管理 Gateway**，負責網站生命週期管理（註冊、刪除、列表、連線測試）。作為「網站資訊」model 的持有人，所有網站相關操作都由此 gateway 統一處理。

**核心職責**：

- 網站註冊（支援 PUBLIC / PRIVATE / REDIRECT / MIRROR 模式）
- 網站刪除（含 L3 資料庫清理）
- 網站清單查詢
- L3 資料庫連線測試
- 委託 auth-gateway 建立網站管理員帳號（預設角色由 auth-gateway 安裝時寫入的 L2 seed 提供）
- 委託 data-gateway 儲存網站資訊記錄

## 3. 啟動流程

```
main.ts
  │
  ├── createGateway()                   ← @dui/framework
  │     ├── L1 init (l1.json)           ← 資料目錄: ./data/
  │     ├── Crypto key init (存入 L1)   ← registerKey() 註冊
  │     ├── Hono app 建立
  │     └── 檔案路由載入 (routes/)
  │
  ├── 安裝檢查 Middleware               ← routes/_middleware.ts
  │     ├── 無 auth_gateway_url 或 data_gateway_url → 視為未安裝
  │     ├── 允許公開路徑（/setup、/css/、/images/、/favicon）
  │     └── 允許公開 API（/api/setup）
  │
  ├── setup 流程 Middleware             ← routes/setup/_middleware.ts
  │     └── 設定「安裝模式」標記到 Context
  │
  └── gw.start()                        ← 啟動 HTTP Server
```

### 3.1 使用 `@dui/framework`

site-gateway 使用 `@dui/framework` 的 `createGateway()` 統一處理以下初始化：

1. **L1 KV Store** — 在 `gateway/site-gateway/data/l1.json` 建立設定儲存
2. **加密金鑰** — 自動產生 256-bit 金鑰，存入 L1 的 `_crypto_key`，透過 `registerKey()` 註冊
3. **Hono 應用程式** — 建立 HTTP server
4. **檔案路由** — 自動載入 `routes/` 目錄下的頁面路由

## 4. 資料目錄

```
gateway/site-gateway/
└── data/
    ├── l1.json                ← L1 設定儲存
    │                           ├── _crypto_key（加密金鑰）
    │                           ├── auth_gateway_url
    │                           └── data_gateway_url
    └── config.json            ← ConfigStore（與 L1 同義，互為鏡像）
```

site-gateway **本身不操作資料庫**。網站資訊記錄透過 data-gateway 的 **L2 CRUD API** 存取；管理員帳號與角色透過 auth-gateway API 建立。

## 5. API 路由

### 5.1 安裝與設定 API

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/setup` | 首次安裝：設定 auth-gateway URL 與 data-gateway URL |

安裝請求主體：

```json
{
  "auth_gateway_url": "http://localhost:8001",
  "data_gateway_url": "http://localhost:8002"
}
```

### 5.2 網站管理 API

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/site/apply` | 申請新網站：建立 L3 資料庫、寫入網站資訊至 L2、透過 auth-gateway `/api/register` 建立網站管理員帳號 |
| POST | `/api/site/test-connection` | 測試 L3 資料庫連線（代理至 data-gateway L3 API） |
| GET | `/api/sites` | 列出所有網站（查詢 data-gateway L2） |
| DELETE | `/api/site/:host` | 刪除網站（含 L3 清理 + 通知 auth-gateway 清除帳號） |

> 網站管理 API 已從 data-gateway 搬遷至此，site-gateway 為網站資訊 model 的持有人。網站管理員帳號透過 auth-gateway 的 `/api/register` 端點建立（角色 `使用者:角色:管理員`）；**預設角色（會員、貴賓、黑名單）與管理員角色由 auth-gateway 安裝時寫入的 L2 seed 提供**，site/apply **不再建立預設角色**。

#### site/apply 處理流程

`POST /api/site/apply`（body：`mode`、`domain`、`title`、`admin`（帳號＋密碼）、`l3` 選填）：

1. 驗證必要欄位與 `mode`（PUBLIC / PRIVATE / REDIRECT / MIRROR）
2. 透過 data-gateway **L3 API**（`POST /api/l3/init`）建立並初始化 L3 資料庫（未提供 `l3` 時預設沿用 L2 同類型資料庫）
3. 透過 auth-gateway `/api/register` 建立網站管理員帳號（角色 `使用者:角色:管理員`，依賴 L2 seed 中的管理員角色）
4. 寫入網站資訊至 data-gateway **L2**：
   - URL：`POST /api/l2/網站資訊/網站資訊`（L2 CRUD，攜帶 `X-API-Key` header）
   - ID：**三段式 composite ID** `網站資訊:網站資訊:{domain}`（如 `網站資訊:網站資訊:example.com`）
5. 回傳建立結果

> 所有對 data-gateway 的呼叫皆帶 `X-API-Key` header（安裝時註冊取得）；對 auth-gateway 的 `/api/register` 呼叫不需 API Key（公開端點）。

### 5.3 檔案路由

`routes/` 目錄下的路由由 `@dui/framework` 的 `loadRoutes()` 自動載入。

| 路徑 | 檔案 | 說明 |
|------|------|------|
| `GET /` | `routes/_lang_` 目錄偵測 → 自動註冊語言偵測 redirect | 依 `Accept-Language` 導向至 `/:lang/` |
| `GET /:lang/` | `routes/_lang_/index.tsx` | 首頁 |
| `GET /:lang/setup` | `routes/_lang_/setup/index.tsx` | 安裝設定頁面 |
| `POST /api/setup` | `routes/api/setup/post.ts` | 首次安裝 |
| `POST /api/site/apply` | `routes/api/site/apply/post.ts` | 申請新網站 |
| `POST /api/site/test-connection` | `routes/api/site/test-connection/post.ts` | 測試 L3 連線 |
| `GET /api/sites` | `routes/api/sites/get.ts` | 網站列表 |
| `GET /api/health` | TBD | 健康檢查 |
| `GET /css/output.css` | `routes/css/output.css` | 靜態樣式檔 |

## 6. 相依關係

```
site-gateway
  ├── @dui/framework          ← createGateway()、fileRouter、Hono
  ├── @dui/util               ← ConfigStore、info / error
  ├── auth-gateway            ← HTTP：建立網站管理員帳號（預設角色由 auth-gateway 安裝時寫入的 L2 seed 提供）
  └── data-gateway            ← HTTP：網站資訊記錄 CRUD（L2 CRUD API，帶 X-API-Key）
```
