# site-gateway 規格書

> 最後更新：2026-08-06

---

## 1. 概述

site-gateway 是 WebCube2027 的**網站管理 Gateway**，負責網站生命週期管理（註冊、刪除、列表、連線測試）。作為「網站資訊」model 的持有人，所有網站相關操作都由此 gateway 統一處理。

**核心職責**：

- 網站註冊（寫入 L2 `網站資訊` collection）
- 網站刪除（含 L2 記錄清理）
- 網站清單查詢
- L3 資料庫連線測試（本地以 `@dui/database` 直接測試）
- 委託 auth-gateway 建立網站管理員帳號
- 以 **SitePool**（繼承 `@dui/pool`）快取 L2 網站資訊，變更延遲寫入、太久未讀自動清除，並經 `/api/health` 輸出快取狀態

**資料邊界**：site-gateway 只操作 **L2 的 `網站資訊` collection**，**沒有 seed**。預設角色／管理員角色由 auth-gateway 安裝時以 L2 seed 寫入；L3 租戶資料庫由 data-gateway 依網站資訊的 `資料庫` 欄位自動建立連線。

## 3. 啟動流程

```
main.ts
  │
  ├── createGateway()                   ← @dui/framework
  │     ├── L1 init (l1.json)           ← 資料目錄: ./data/
  │     ├── Crypto key init (存入 L1)   ← registerKey() 註冊
  │     ├── Hono app 建立
  │     └── 檔案路由載入 (routes/)
  │
  ├── initSiteConfig()                  ← utils/config.ts（ConfigStore: config.json）
  │
  ├── 安裝檢查                           ← 讀取 auth_gateway_url / data_gateway_url
  │     ├── 已安裝 → setAuthGatewayUrl()（verifyToken 可拉取 Ed25519 公鑰）
  │     └── 未安裝 → 記錄提示，導向 /setup
  │
  └── gw.start()                        ← 啟動 HTTP Server
```

### 3.1 使用 `@dui/framework`

site-gateway 使用 `@dui/framework` 的 `createGateway()` 統一處理以下初始化：

1. **L1 KV Store** — 在 `gateway/site-gateway/data/l1.json` 建立設定儲存
2. **加密金鑰** — 自動產生 256-bit 金鑰，存入 L1 的 `_crypto_key`，透過 `registerKey()` 註冊
3. **Hono 應用程式** — 建立 HTTP server
4. **檔案路由** — 自動載入 `routes/` 目錄下的頁面路由

## 4. 資料目錄

```
gateway/site-gateway/
└── data/
    ├── l1.json                ← L1 設定儲存
    │                           ├── _crypto_key（加密金鑰）
    │                           ├── auth_gateway_url
    │                           └── data_gateway_url
    └── config.json            ← ConfigStore（與 L1 同義，互為鏡像）
                                 ├── auth_gateway_url
                                 ├── data_gateway_url
                                 ├── data_gateway_api_key（註冊取得）
                                 └── ed25519_public_key（auth-gateway 公鑰）
```

site-gateway **本身不直接操作資料庫**。網站資訊記錄透過 SitePool 快取並延遲寫入 data-gateway 的 **L2 CRUD API**；管理員帳號與角色透過 auth-gateway API 建立。

## 5. SitePool — 網站資訊快取

`services/site-pool.ts` 繼承 `@dui/pool` 的 `BasePool<string, SiteCacheValue>`，是 site-gateway 的核心：

| 能力 | 設定 | 說明 |
|------|------|------|
| 快取 | `maxSize: 5000` | key = domain（LRU 排序） |
| 延遲寫入 | `flushIntervalMs: 5000` | `upsert()` 先寫入 pool 標記 dirty，`onFlush` 每 5 秒 batch PUT 回 L2 |
| 太久未讀自動清除 | `maxIdleMs: 10 分鐘`、`cleanupIntervalMs: 60 秒` | 超過 10 分鐘未存取自動 evict，避免記憶體膨脹 |
| 狀態輸出 | `getStatus()` / `getItemsOverview()` | 供 `/api/health` 與首頁顯示（快取數、命中率、待 flush、逐項目明細） |

**操作介面**：

| 方法 | 說明 |
|------|------|
| `getSite(domain)` | pool hit 直接回傳；miss 向 data-gateway L2 查詢並填入 pool（`set(..., false)` 不標記 dirty） |
| `upsert(domain, record)` | 建立／更新：寫入 pool 並標記 dirty，由 flush 週期寫回 L2 |
| `removeSite(domain)` | 先 flush 該筆 dirty 資料避免遺失，再向 data-gateway 發送 DELETE |
| `buildId(domain)` | 產生 composite ID `網站資訊:網站資訊:{domain}` |

> 快取的「網站資訊」記錄欄位依 Model 定義（`database/models/網站資訊.ts`）：`網址`、`名稱`、`描述`、`商標`、`模式`、`設定`、`資料庫`（L3 連線 JSON 字串）、`狀態`、`開始日期`、`作者` 等。

## 6. API 路由

### 6.1 公開 API（不需登入）

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/health` | 健康檢查：data-gateway 連線狀態 + SitePool 快取快照 |
| GET | `/api/version` | 版本號（從 `deno.json` 動態讀取） |
| POST | `/api/setup` | 首次安裝：設定 auth-gateway URL、data-gateway URL 與 Master Key，向 data-gateway 註冊取得 API Key |
| POST | `/api/site/apply` | 申請新網站：SitePool 延遲寫入 L2 網站資訊 + 委託 auth-gateway `/api/register` 建立管理員 |
| POST | `/api/site/test-connection` | 測試 L3 資料庫連線（本地 `createAdapter` 測試） |
| GET | `/api/sites` | 列出所有網站（查詢 data-gateway L2 網站資訊）＋附帶 SitePool 狀態 |

### 6.2 POST /api/setup

安裝請求主體：

```json
{
  "auth_gateway_url": "http://localhost:8001",
  "data_gateway_url": "http://localhost:8002",
  "master_key": "由 data-gateway 管理員提供"
}
```

流程：

1. 驗證欄位與 URL 格式
2. 向 data-gateway `POST /api/register-gateway` 註冊（name: `site-gateway`，權限僅 `網站資訊: { 讀: true, 寫: true }`）取得專屬 API Key
3. 寫入 ConfigStore：`auth_gateway_url` / `data_gateway_url` / `data_gateway_api_key`
4. 呼叫 `setAuthGatewayUrl()`（供 `@dui/util/jwt` 的 `verifyToken` 拉取 Ed25519 公鑰）

> site-gateway 註冊的權限僅 `網站資訊`（讀/寫），**只操作 L2 的 `網站資訊` collection，沒有 seed**。

### 6.3 POST /api/site/apply

`POST /api/site/apply`（body：`domain`、`名稱`、`描述?`、`商標?`、`模式?`、`l3?`、`admin?`）：

1. 驗證 domain（正規化 hostname 為小寫 + 格式檢查）與網站名稱
2. 檢查重複（`sitePool.getSite(domain)`，已存在回傳 409）
3. 組裝網站資訊記錄（ID 為三段式 composite ID `網站資訊:網站資訊:{domain}`；`資料庫` 欄位為 L3 連線設定的 JSON 字串）
4. `sitePool.upsert(domain, record)` 寫入 SitePool（延遲寫入 L2，每 5 秒 batch flush）
5. 若提供 `admin`（帳號＋密碼）→ 委託 auth-gateway `/api/register` 建立網站管理員；**失敗則回滾**（`removeSite(domain)`）
6. L3 資料庫不需在此初始化 — data-gateway 收到帶 `X-Tenant` 的請求時自動建立連線

> 所有對 data-gateway 的呼叫皆帶 `X-API-Key` header（安裝時註冊取得）；對 auth-gateway 的 `/api/register` 呼叫不需 API Key（公開端點）。

### 6.4 檔案路由

`routes/` 目錄下的路由由 `@dui/framework` 的 `loadRoutes()` 自動載入。

| 路徑 | 檔案 | 說明 |
|------|------|------|
| `GET /` | `routes/index.tsx` | 首頁（無語言前綴，重導向至 `/:lang/`） |
| `GET /:lang/` | `routes/_lang_/index.tsx` | 首頁（GatewayHero + SitePool 狀態卡） |
| `GET /:lang/setup` | `routes/_lang_/setup/index.tsx` | 安裝設定頁面 |
| `GET /:lang/doc.md` | `routes/_lang_/doc.md` | API 文件（Markdown 自動轉 HTML） |
| `GET /:lang/history.md` | `routes/_lang_/history.md` | 版本紀錄（Markdown 自動轉 HTML） |
| `POST /api/setup` | `routes/api/setup/post.ts` | 首次安裝 |
| `POST /api/site/apply` | `routes/api/site/apply/post.ts` | 申請新網站 |
| `POST /api/site/test-connection` | `routes/api/site/test-connection/post.ts` | 測試 L3 連線 |
| `GET /api/sites` | `routes/api/sites/get.ts` | 網站列表 |
| `GET /api/health` | `routes/api/health/get.ts` | 健康檢查 |
| `GET /api/version` | `routes/api/version/get.ts` | 版本號 |
| `GET /css/output.css` | `routes/css/output.css` | 靜態樣式檔 |

### 6.5 根中介層

`routes/_middleware.ts`：

1. **語言注入**：從 `lang` cookie → `Accept-Language` 解析最佳語言，注入 `c.get('lang')`
2. **公開路徑放行**：`/setup`、`/css/`、`/images/`、`/favicon`、`/api/health`、`/api/version` 與靜態資源
3. **安裝檢查**：未安裝時 `/api/*` 放行、頁面重導向 `/:lang/setup`
4. **JWT 驗證注入**（已安裝）：`extractToken` → `verifyToken`（Ed25519），成功則注入 `jwt_payload` / `tenant` / `jwt_type` / `帳號` / `角色` / `權限`；無 JWT 或驗證失敗不阻擋

## 7. 相依關係

```
site-gateway
  ├── @dui/framework          ← createGateway()、fileRouter、GatewayLayout、health/version handler
  ├── @dui/util               ← ConfigStore、info / error
  ├── @dui/util/jwt           ← extractToken / verifyToken（Ed25519 公鑰驗證）
  ├── @dui/pool               ← SitePool 基底（BasePool）
  ├── @dui/database           ← site/test-connection 本地測試 adapter
  ├── auth-gateway            ← HTTP：建立網站管理員帳號（角色 seed 由 auth-gateway 提供）
  └── data-gateway            ← HTTP：網站資訊記錄 CRUD（L2 CRUD API，帶 X-API-Key）
```
