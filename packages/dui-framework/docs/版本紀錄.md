# @dui/framework 版本紀錄

> 版本紀錄已從規格書獨立出來。最新版本請參考 `deno.json`。

| 版本 | 日期 | 說明 |
|------|------|------|
| 0.3.0 | 2026-08-01 | **重大重構**：移除 L1Store 建立與 crypto key 管理（移至 `@dui/util` ConfigStore）；`createGateway()` 純化為 Hono + 檔案路由；`Gateway` 介面簡化為 `{ app, dataDir, port, start() }`（移除 `gw.l1`）；移除 `./setup-guard` export |
| 0.2.0 | 2026-07-28 | 新增 `MiddlewareFn` 型別匯出；`route-loader.ts` 最佳化：notFound handler 改為 `runHandlerChain()` 取代 inline 閉包，減少 GC 負擔；`mod.ts` 補上 `MiddlewareFn` 型別匯出 |
| 0.1.0 | 2026-07-22 | 初始版本（Hono + 檔案路由 + gateway lifecycle） |
