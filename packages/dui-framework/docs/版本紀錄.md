# @dui/framework 版本紀錄

> 版本紀錄已從規格書獨立出來。最新版本請參考 `deno.json`。

| 版本 | 日期 | 說明 |
|------|------|------|
| 0.7.1 | 2026-08-06 | **Seed-sync 改走 level root batch**：`syncSeeds` 不再依 `collection:model` 分組發送多個 `PUT /api/{level}/{collection}/{model}`，改為直接發送 `PUT /api/{level}/`（單一端點），由 level batch handler 依 composite ID 自動路由。 |
| 0.7.0 | 2026-08-06 | **Alpine.js 支援 + 註冊順序保證**：新增 `alpine.ts` 模組（`ALPINE_JS_PATH` `/alpine.min.js`、`ALPINE_VERSION` 3.14.9、`getAlpineDist` 讀取 vendor dist、`mountAlpineAssets` 註冊 GET 端點、`alpineScripts` 輸出 `<script defer>` 標籤字串）；`createGateway()` 新增 `alpine?: boolean` 選項，啟用時於載入檔案路由前先掛載 Alpine runtime；`loadRoutes()` 新增 `existingApp` 參數可直接註冊到既有 Hono 實例（保留 Pass 3 notFound 退回機制）——**Hono 依註冊順序匹配路由**，先註冊的靜態路徑 `/alpine.min.js` 才不會被 `_lang_` 轉換的單段參數路由 `/:lang` 搶走（實測修正：原為 loadRoutes 先建 app 再掛 Alpine，`/alpine.min.js` 回傳首頁 HTML）。`generatePageCss()` 新增 `options.safelist`：Alpine 元件移至外部 app.js 後動態 class（如 `badge-success`）不會被 UnoCSS 掃到，需以 safelist 補 CSS。 |
| 0.6.0 | 2026-08-05 | **Seed 同步模組 `seed-sync.ts`**：提供 `loadSeeds` / `computeSeedsHash` / `detectSeedLevels` / `syncSeeds` / `syncAllSeeds` / `seedHashKey`。每個 Gateway 的 seed 位於自身 `database/seeds/<L1|L2|L3>/`，以內容 hash（SHA-256）比對版本，版本不同時**依 `collection:model` 分組以批次 PUT（upsert）覆寫至 data-gateway**（每分組一次 HTTP request，單次最多 100 筆，支援 `X-Tenant`）；版本 hash 存各 Gateway 本機 ConfigStore（`seed_hash_{LEVEL}`），全部成功才更新。**修復 `createGateway()` 傳 string 給 `loadRoutes()`（需 URL）導致檔案路由靜默失效、Gateway 以空 app 運行的既有 bug**；補上 mod.ts 缺失的匯出（`generatePageCss` / `UNOCSS_THEME_COLORS` / `COMPONENT_CSS` / `checkAccess` / `checkPermission` / `extractCollection` 及型別），與規格書 3.1 表一致。 |
| 0.5.1 | 2026-08-04 | **修復 `del.ts` 路由未註冊**：`parseRouteFileInfo` 將 `del.ts` 解析為 `DEL`，不在 `HTTP_METHODS`（僅有 `DELETE`）集合中導致被跳過，所有 gateway 的 DELETE 路由（如 `_id_/del.ts`）回傳 404。修正：`DEL` 明確對應到 `DELETE`。 |
| 0.5.0 | 2026-08-03 | 新增權限工具模組 `permission.ts`（由 data-gateway 搬入並統一）：匯出 `PermissionMap` 等型別與 `mergePermissions` / `checkAccess` / `checkPermission` / `extractCollection` 函式，供各 Gateway 共用（auth-gateway 的 verify-user 改由此匯入 `mergePermissions`；data-gateway 移除其 `utils/permission.ts` 複本與 CRUD handler 的角色權限檢查）。 |
| 0.4.0 | 2026-08-02 | **Fallback 退回機制 + XSS 防護 + 效能最佳化**：新增 Pass 3 階層降級退回（notFound 逐層剝皮 → 母路由 + `rest_path` + param 遮蔽注入動態參數）；`createGateway()` 直接以 `loadRoutes()` 結果作為 app（避免 `app.route()` 不複製 notFoundHandler 導致退回失效）；Markdown title 統一由 route-loader 以 `escapeHtml()` 跳脫，layout 以 `raw(title)` 標記避免雙重跳脫；靜態檔案預載失敗降級為 runtime 重讀（不再靜默失去路由）；fallback 複用原 Context（降 GC、保留 `c.set()` 變數）；`patternSegs` 於初始化預先拆解；`extractTitle` 忽略 YAML Front Matter 並剝除 HTML 標籤；`api-console` 加入 DOM 就緒防呆（`readyState` 判斷） |
| 0.3.0 | 2026-08-01 | **重大重構**：移除 L1Store 建立與 crypto key 管理（移至 `@dui/util` ConfigStore）；`createGateway()` 純化為 Hono + 檔案路由；`Gateway` 介面簡化為 `{ app, dataDir, port, start() }`（移除 `gw.l1`）；移除 `./setup-guard` export |
| 0.2.0 | 2026-07-28 | 新增 `MiddlewareFn` 型別匯出；`route-loader.ts` 最佳化：notFound handler 改為 `runHandlerChain()` 取代 inline 閉包，減少 GC 負擔；`mod.ts` 補上 `MiddlewareFn` 型別匯出 |
| 0.1.0 | 2026-07-22 | 初始版本（Hono + 檔案路由 + gateway lifecycle） |
