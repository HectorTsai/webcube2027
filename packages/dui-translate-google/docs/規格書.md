> 最後更新：2026-07-28

## 概述

`@dui/translate-google` 是 Google Translate 的無 API Key 客戶端，原先內嵌於 `@dui/smartmultilingual`，現已抽取為獨立套件。採用 `TranslationProvider` 介面，可無痛替換為 AI 翻譯或其他實作。

---

## 安裝

此套件為 WebCube2027 workspace 成員，無需額外安裝：

```json
{
  "imports": {
    "@dui/translate-google": "./packages/dui-translate-google/mod.ts"
  }
}
```

## TranslationProvider 介面

所有翻譯提供者實作此介面，確保可互換性：

```typescript
interface TranslationProvider {
  translate(text: string, targetLang: string, sourceLang?: string): Promise<string>;
}
```

| 參數 | 型別 | 說明 |
|------|------|------|
| `text` | `string` | 要翻譯的文字 |
| `targetLang` | `string` | 目標語言代碼 (如 `"zh-TW"`, `"en"`, `"ja"`) |
| `sourceLang` | `string` (可選) | 來源語言代碼，未指定時自動偵測 (`"auto"`) |

回傳：翻譯後的字串。

## GoogleTranslationProvider

Google Translate 實作，使用公開的 `translate.google.com` 端點（免 API Key）。

```typescript
import { GoogleTranslationProvider } from '@dui/translate-google';

const translator = new GoogleTranslationProvider();
const result = await translator.translate("Hello world", "zh-TW");
// "你好，世界"
```

### 特性

- **免 API Key**：直接爬取 Google Translate 公開頁面
- **tk 驗證**：自動產生 Google 要求的 `tk` 參數（TKK 金鑰每小時換）
- **Single-flight**：跨小時瞬間大量請求時，TKK 更新只觸發一次 HTTP 請求
- **User-Agent**：帶 Chrome 瀏覽器 UA，降低被 429/403 阻擋的機率
- **POST 降級**：URL 超過 2048 字元時自動切換 POST

### 錯誤處理

翻譯失敗時回傳原始文字（fallback），不拋出例外。可自行在外部 catch：

```typescript
try {
  const result = await translator.translate(text, targetLang);
} catch (err) {
  // 僅在 googleTranslateRequest 內部錯誤時觸發
}
```

## generateGoogleTranslateToken

低階函式，產生 `tk` 驗證參數：

```typescript
import { generateGoogleTranslateToken } from '@dui/translate-google';

const token = await generateGoogleTranslateToken("Hello world");
// { name: "tk", value: "123456.789012" }
```

## 註冊為預設翻譯服務

與 `@dui/smartmultilingual` 整合：

```typescript
import { registerTranslation } from '@dui/smartmultilingual';
import { GoogleTranslationProvider } from '@dui/translate-google';

registerTranslation(new GoogleTranslationProvider());
```

## AI 翻譯注入模式

任何符合 `TranslationProvider` 介面的實作均可注入：

```typescript
class OpenAITranslationProvider implements TranslationProvider {
  async translate(text: string, targetLang: string, sourceLang?: string) {
    // 實作 OpenAI API 呼叫...
  }
}

registerTranslation(new OpenAITranslationProvider());
```

## 內部實作細節

### google_token.ts

| 項目 | 說明 |
|------|------|
| TKK 狀態 | 模組級 `currentTokenKey`，無 Map/globalState 冗餘 |
| 金鑰更新 | `ensureTokenKey()` 以小時為單位檢查過期，`updatePromise` 單飛防併發 |
| UTF-8 編碼 | `TextEncoder.encode()` 原生實作，取代手動 30 行 Surrogate Pair 計算 |

### google.ts

| 項目 | 說明 |
|------|------|
| 固定參數 | `BASE_PARAMS` 預串 10 個 `dt=`，`URLSearchParams()` 初始化取代迴圈 append |
| User-Agent | `Mozilla/5.0 ... Chrome/120` |
| 長 URL 降級 | 超過 2048 字元時 POST 提交，減少請求被攔截的機會 |
