# @dui/util 版本紀錄

> 版本紀錄已從規格書獨立出來。最新版本請參考 `deno.json`。

| 版本 | 日期 | 說明 |
|------|------|------|
| 0.6.0 | 2026-08-03 | **新增 `gwFetch`**：跨 Gateway HTTP 客戶端，自動攜帶語言（`Accept-Language`）、租戶（`X-Tenant`）、身份（`Cookie`），供後端內網統一呼叫其他 gateway |
| 0.5.0 | 2026-08-01 | **新增 `ConfigStore`**：輕量持久化 JSON KV（atomic write + dirty-flag coalescing flush），取代原 `@dui/kv` L1Store；JWT 模組移除 `dataPool` 依賴，改為 `setAuthGatewayUrl()` + `AUTH_GATEWAY_URL` 環境變數 |
| 0.4.0 | 2026-07-28 | Crypto v2 格式（直接 AES-GCM，跳過 PBKDF2）；`@std/encoding/base64` 取代手動 Base64；`@std/path` `dirname()` 取代手動路徑截取；CryptoKey 模組級快取；jwt.ts Hono `Context` 型別取代 `any` + 靜態導入 `hono/jwt` + 泛型 `verifyToken<T>()`；SecretString `process()` 併發安全 guard；InnerAPI 快取保留原始 Headers + URL 安全正規化；Logger 序列化寫入佇列防 ResourceBusy；deno.json 新增 `@std/path`、`@std/encoding/base64`；**補全 7 個子路徑匯出（`.`、`./logger`、`./InnerAPI`、`./crypto`、`./secretstring`、`./response`、`./jwt`）** |
| 0.3.0 | 2026-07-26 | hono/jwt 動態導入改為頂層靜態導入（暫緩，因 JSR 鎖定版本） |
| 0.2.0 | 2026-07-24 | 重新命名 `SecretString`、`InnerAPI`、`設定App`、`取得域名`；補上 `ensureKey` 匯出；`response.ts` 加入 `ErrorCode` 與泛型 `SuccessResponse<T>` |
| 0.1.0 | 2026-07-22 | 初始版本（crypto、jwt、logger、response、InnerAPI） |
