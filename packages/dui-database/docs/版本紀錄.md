# @dui/database 版本紀錄

> 版本紀錄已從規格書獨立出來。最新版本請參考 `deno.json`。

| 版本 | 日期 | 說明 |
|------|------|------|
| 0.5.2 | 2026-08-05 | **修復 SQLite `delete()` 語意**：改以 `stmt.run()` 的 `changes > 0` 判定紀錄是否存在，不再一律回傳 `true`（與 MSSQL/MongoDB 等其他 adapter 語意一致）。修正批次 CRUD 中刪除不存在的 id 被誤報為成功、單筆 `DELETE /:id` 對不存在的紀錄回傳 200（應為 404）的問題。 |
| 0.5.1 | 2026-08-02 | **安全強化 + ping 機制**：新增可選 `ping?()` 介面並由全部 9 個 adapter 實作，`onHeartbeat()`/`testConnection()` 改走輕量 ping（避免對不存在的 `_heartbeat_` 表 count() 汙染 DB log）；`testConnection()` 移除重複 connect；SQLite/MySQL/PostgreSQL/SurrealDB/MSSQL 所有 SQL 方法的 collection 與 filter.field 全面以 `isSafeIdentifier()` 驗證，LIKE 以 `escapeLike()` 轉義；Appwrite/Firestore `patch()` 改為保留 `{ data }` 包裹結構（讀取合併／dot notation）；MongoDB/Surreal `queryByField()` 移除 `LIMIT 1` 符合陣列規格；BaseModel id getter 修正（table 空時不輸出 `:type:id`）+ constructor 防 Invalid Date；MSSQL 改用 `safeModel` 供索引命名 |
| 0.5.0 | 2026-08-01 | **重大重構**：移除 `PoolCore`/`dataPool`/`pool.ts`；移除 `@dui/kv` 相依；改為純 `AdapterPool`（extends `@dui/pool` BasePool）＋ Registry Pattern；層級管理（L2/L3）移至 `data-gateway` 的 `DbManager`；新增 `types.ts`；簡化匯出項目 |
| 0.4.1 | 2026-07-28 | PoolCore override `getItemsOverview()` 回傳 `DbPoolItemOverview[]`（含 `dbName`/`isSystem`）；re-export `PoolStatus`/`PoolItemOverview`/`DbPoolItemOverview` 型別 |
| 0.4.0 | 2026-07-28 | Registry Pattern 取代 switch-case；initL2/initL3 Promise single-flight；SQLite `UPDATE ... RETURNING`；`sanitizePayload()` 統一函式；`applyMemoryFilter()` / `applyMemorySort()`；SurrealDB `esc()` + count 容錯；MSSQL 表名安全防護；`PoolCore.shutdownAll()` + signal listener；`toJSON()` 動態收集子類別屬性 |
| 0.3.0 | 2026-07-26 | L1Store 獨立到 `@dui/kv`；MSSQL / DynamoDB Adapter 加入；Adapter 連線簽名修正；Firestore 複合索引錯誤提示 |
| 0.2.0 | 2026-07-24 | Appwrite Adapter 加入；count() 方法統一；listAll() 合併去重修正；內建 response 正規化 |
| 0.1.0 | 2026-07-22 | 初始版本（SurrealDB / SQLite / MongoDB / MySQL / PostgreSQL / Firestore） |
