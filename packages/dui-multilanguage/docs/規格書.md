## 概述

多國語言內容資料型態套件。提供結構化的多語言資料模型（字串、二進位、智慧內容），自動翻譯整合（`TranslationProvider` 介面），以及內容渲染與資源偵測工具。

## 核心類別

### MultilingualObject\<T\>

基底抽象類別，封裝「語言 → 值」的對應關係。

```typescript
abstract class MultilingualObject<T> {
  constructor(data?: MultilingualData<T>);
  get(lang: string): T | undefined;
  set(lang: string, value: T | undefined): void;
  has(lang: SupportedLanguage): boolean;
  delete(lang: SupportedLanguage): boolean;
  getAllAvailableLanguages(): SupportedLanguage[];
  getFirstAvailableLanguage(): SupportedLanguage | null;
  findBestSourceLanguage(preferredLang?): SupportedLanguage | null;
  toJSON(languageSet?): MultilingualData<T>;
  toString(): string;
  clone(): MultilingualObject<T>;
  protected translate(text: string, from: SupportedLanguage, to: SupportedLanguage): Promise<string>;
}
```

### MultilingualString

字串型多語言內容。

```typescript
class MultilingualString extends MultilingualObject<string> {
  constructor(data?: MultilingualData<string>);
  // 繼承所有 MultilingualObject 方法
}
```

### MultilingualBinary

二進位資料型多語言內容（圖片、文件等）。

```typescript
class MultilingualBinary extends MultilingualObject<Uint8Array> {
  constructor(data?: MultilingualData<Uint8Array>);
  // 繼承所有 MultilingualObject 方法
}
```

### MultilingualSmartContent

智慧內容型多語言內容。每個語言可包含不同格式的文字（純文字、Markdown、HTML、SVG），支援自動翻譯。

```typescript
class MultilingualSmartContent extends MultilingualObject<SmartContent> {
  constructor(data?: MultilingualData<SmartContent>);
  // 繼承所有 MultilingualObject 方法
  // 翻譯時自動偵測格式、只翻譯文字部分
}
```

## 翻譯服務

### TranslationProvider 介面

```typescript
interface TranslationProvider {
  translate(text: string, targetLang: string, sourceLang?: string): Promise<string>;
}
```

### 使用方式

```typescript
import { registerTranslation, getTranslation } from '@dui/smartmultilingual';
import { GoogleTranslationProvider, type TranslationProvider } from '@dui/translate-google';

// 註冊 Google Translate（同步註冊）
registerTranslation(new GoogleTranslationProvider());

// 取得翻譯服務並使用（async，未註冊時動態載入 Google 為預設）
const translator = await getTranslation();
const result = await translator.translate("Hello", "zh-TW");

// 註冊自訂 AI 翻譯（無需安裝 @dui/translate-google）
class MyAIProvider implements TranslationProvider {
  async translate(text: string, targetLang: string, sourceLang?: string) {
    // 自訂實作
  }
}
registerTranslation(new MyAIProvider());
```

## SmartContent 與 ContentRenderer

### SmartContent

智慧內容資料結構，包含格式標記與原始內容。

```typescript
interface SmartContent {
  format: SupportedFormat;      // TEXT | MARKDOWN | HTML | SVG | JSON | PNG | ...
  content: string;              // 原始內容
  metadata?: Record<string, unknown>;
}
```

### ContentRenderer

將不同格式的內容渲染為目標輸出。

```typescript
class ContentRenderer {
  static async toHTML(content: SmartContent): Promise<string>;
  static async toPlainText(content: SmartContent): Promise<string>;
  static async render(content: SmartContent, format: string): Promise<string>;
}
```
