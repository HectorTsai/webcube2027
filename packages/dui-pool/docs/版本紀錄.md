# @dui/pool 版本紀錄

> 版本紀錄已從規格書獨立出來。最新版本請參考 `deno.json`。

| 版本 | 日期 | 變更 |
|------|------|------|
| 0.3.0 | 2026-07-28 | **新增可觀測性**：`PoolStatus` 快照（容量/效能/執行中狀態/時間戳/錯誤）、`PoolItemOverview` 項目元資料（不含 value）、`getStatus()`、`resetMetrics()`、`getItemsOverview()`（可 override）；內部計數器自動追蹤 `hits/misses/evictions/flushes/flushErrors`；定時器自動紀錄 `lastFlushAt/lastCleanupAt/lastHeartbeatAt`；catch 區塊自動紀錄 `lastError`；`deno.json` 版本 0.3.0 |
| 0.2.0 | 2026-07-28 | **flushToStorage()** 寫入成功後才清 dirty flag；**delete()** 改為 async，先 flush dirty 再 onEvict；**destroy()** 改為 async，依序 flush → onEvict → clear；**cleanupExpired()** dirty 項目先 flush 再 evict；**三個定時器**皆加入防重疊鎖 + try/catch；**軟水位線**（`highWatermarkRatio` 預設 0.8）背景非同步 LRU 淘汰；**硬上限**（`maxSize`）同步緊急 LRU 淘汰，全 persistent 時拋 `PoolFullError`；**MinSize** heartbeat 自動預熱 `onWarmup()`；**O(1) LRU** get()/set() 利用 Map delete+set 重排；**keysIterator()** 串流迭代器；`deno.json` 新增 `@dui/util`、`maxSize`、`highWatermarkRatio`、`minSize` 選項 |
| 0.1.0 | 2026-07-23 | 初始規格：BasePool、PoolItem、PoolOptions、persistent flag、三種定時器 |
