# @dui/pool 版本紀錄

> 版本紀錄已從規格書獨立出來。最新版本請參考 `deno.json`。

| 版本 | 日期 | 變更 |
|------|------|------|
| 0.4.0 | 2026-08-07 | **三層 Pool 架構 + TaskPool + 快取形狀安全化**（對應 commit `ef18588`）：<br>**① PoolBase（抽象共用底座）**：由 BasePool 拆出——cleanup/heartbeat 兩定時器（防重疊鎖 + try/catch + `_lastCleanupAt`/`_lastHeartbeatAt`/`_lastError` 觀測）、抽象 hooks（`cleanup()`/`onHeartbeat()`/`getCurrentSize()`）、`reconfigure()`/`destroy()`、不持項目容器；<br>**② BasePool<K,V>（儲存語意）**：項目容器 `Map<K, PoolItem<V>>`、O(1) LRU、dirty flag + 延遲批量寫回（`onFlush`）、idle eviction（`onEvict`）、persistent 保護、軟水位線（`highWatermarkRatio` 0.8）/硬上限（`maxSize`→`PoolFullError`）、minSize 自動預熱（`onWarmup`）、可觀測性（`getStatus`/`resetMetrics`/`getItemsOverview`）；<br>**③ CachePool<K,V>（read-through 快取）**：`getOrFetch(key, fetcher, ttlMs?)`、TTL 過期（與 idle 獨立）、`invalidateByPrefix()`（跳過 dirty）、`clearCache()`、`onFlush`/`onEvict` 空實作、強化狀態（`avgIdleMs`/`utilizationRate`）；<br>**④ DataPool<V>（DG 通訊代理）**：resolver（`getDgUrl`/`getApiKey`）、`request()` 通用代理、`fetch`/`fetchMany` 便捷抓取、泛用 CRUD（`getById`/`list`/`create`/`update`/`remove`）、快取 key = `${level}:${collection}:${id}`；<br>**⑤ TaskPool（優先權佇列 + 並行 worker）**：多佇列（`queues`，priority 小者優先、可設 per-queue `concurrency`，預設 `default` 佇列）、`exec(queueOrTask, task?)`、自動擴縮（`autoScale`，`pressure = totalPending/maxConcurrency`，擴縮條件 `>scaleUpThreshold 0.8`/`<scaleDownThreshold 0.3`，`cooldownMs` 30s）、背壓（`maxQueueSize` 1000，滿則 reject）、`dataSource` 整包注入 `ctx.data`、`getStatus(): TaskPoolStatus`；<br>**⑥ 型別擴充**：新增 `PoolBaseOptions`、`TaskQueueConfig`、`TaskPoolOptions`、`TaskPoolStatus`、`PoolItemOverview` 擴充（`isPersistent`/`maxIdleMs`/`remainMs`）；<br>**⑦ 快取形狀契約（重要）**：`getById` 回傳型別受 `T extends V` 約束、`create`/`update`(PUT) 不再自動寫入快取改由 Typed Wrapper 決定，杜絕「泛型方法裸寫 DG json → 同一 key 兩種形狀解包失敗」（實例：auth-gateway 變更密碼後「使用者不存在」）；<br>**配套**：auth-gateway `AccountPool` 改為 `extends DataPool`，保留 verifyPassword/lockout/role permissions；`gateway規格書` 第 13 章改為 DataPool 通用規範 |
| 0.3.0 | 2026-07-28 | **新增可觀測性**：`PoolStatus` 快照（容量/效能/執行中狀態/時間戳/錯誤）、`PoolItemOverview` 項目元資料（不含 value）、`getStatus()`、`resetMetrics()`、`getItemsOverview()`（可 override）；內部計數器自動追蹤 `hits/misses/evictions/flushes/flushErrors`；定時器自動紀錄 `lastFlushAt/lastCleanupAt/lastHeartbeatAt`；catch 區塊自動紀錄 `lastError`；`deno.json` 版本 0.3.0 |
| 0.2.0 | 2026-07-28 | **flushToStorage()** 寫入成功後才清 dirty flag；**delete()** 改為 async，先 flush dirty 再 onEvict；**destroy()** 改為 async，依序 flush → onEvict → clear；**cleanupExpired()** dirty 項目先 flush 再 evict；**三個定時器**皆加入防重疊鎖 + try/catch；**軟水位線**（`highWatermarkRatio` 預設 0.8）背景非同步 LRU 淘汰；**硬上限**（`maxSize`）同步緊急 LRU 淘汰，全 persistent 時拋 `PoolFullError`；**MinSize** heartbeat 自動預熱 `onWarmup()`；**O(1) LRU** get()/set() 利用 Map delete+set 重排；**keysIterator()** 串流迭代器；`deno.json` 新增 `@dui/util`、`maxSize`、`highWatermarkRatio`、`minSize` 選項 |
| 0.1.0 | 2026-07-23 | 初始規格：BasePool、PoolItem、PoolOptions、persistent flag、三種定時器 |
